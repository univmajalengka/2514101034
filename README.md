# Website Panduan Pendakian Gunung Tampomas

## Tentang Website

Landing page informasi pendakian Gunung Tampomas di Kabupaten Sumedang. Website memuat informasi pendakian, dua lokasi basecamp, galeri foto perjalanan, panduan persiapan, dan pilihan paket guide.

## Fitur

- Peta Google Maps untuk Basecamp via Cibeureum dan BC Cibueuk Padasari.
- Tautan ke video pendakian Gunung Tampomas di YouTube.
- Galeri foto perjalanan.
- Pilihan paket dan halaman booking dengan tautan WhatsApp basecamp.

## Teknologi

- HTML
- CSS
- Bootstrap CSS

Website ini dibuat dengan HTML dan CSS, tanpa PHP, JavaScript, atau database. Formulir booking hanya berupa tampilan; isiannya tidak dikirim otomatis. Untuk bertanya atau mengajukan booking, hubungi basecamp melalui WhatsApp.

## Cara Menjalankan

1. Buka `index.html` langsung di browser, atau salin folder `pertemuan3` ke folder `www` Laragon.
2. Jika folder berada langsung di `www`, jalankan Laragon lalu buka `http://localhost/pertemuan3/`.
3. Halaman booking tersedia di `booking.html` atau `http://localhost/pertemuan3/booking.html`.

Foto-foto website berada di `assets/foto/`.
